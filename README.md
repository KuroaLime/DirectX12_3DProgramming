# DirectX12 3D Programming

DirectX 12(C++)로 직접 구현한 3D 그래픽스 프로그래밍 프로젝트 모음입니다.
렌더링 파이프라인, 충돌 판정, 게임 로직까지 라이브러리 없이 로우레벨로 작성했습니다.

## 프로젝트

### [지형 렌더링 & 헬기 전투 시스템](./지형%20렌더링%20%26%20헬기%20전투%20시스템%20%28DirectX12%29/)

테셀레이션 지형 위를 헬기로 비행하며 미사일로 전투를 벌이는 3D 액션 데모입니다.

**구현 내용**

| 기능 | 설명 | 코드 |
|---|---|---|
| 지형 테셀레이션 | Hull/Domain Shader로 카메라 거리 기반 동적 분할 | [TopographyShader.cpp](./지형%20렌더링%20%26%20헬기%20전투%20시스템%20%28DirectX12%29/TopographyShader.cpp) |
| 3D 충돌 판정 | GJK/EPA 알고리즘 + 공간 분할 그리드 브로드페이즈 | [Collision.cpp](./지형%20렌더링%20%26%20헬기%20전투%20시스템%20%28DirectX12%29/Collision.cpp) |
| 실시간 그림자 | Depth-only Shadow Map 패스, PCF 샘플링 | [Scene.cpp](./지형%20렌더링%20%26%20헬기%20전투%20시스템%20%28DirectX12%29/Scene.cpp) |
| 거울 반사 | 스텐실 버퍼 기반 Mirror Reflection PSO | [Shader.cpp](./지형%20렌더링%20%26%20헬기%20전투%20시스템%20%28DirectX12%29/Shader.cpp) |
| 전투 로직 | 헬기 조종, 락온, 미사일 발사/폭발 | [BattleScene.cpp](./지형%20렌더링%20%26%20헬기%20전투%20시스템%20%28DirectX12%29/BattleScene.cpp) |

**조작법**

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 전/후진, 좌/우 이동 |
| `↑` `↓` `←` `→` | 이동 (연속 입력) |
| `Q` / `R` | 상승 / 하강 |
| `Shift` / `Ctrl` | 상승 / 하강 |
| 마우스 좌클릭 + 드래그 | 시점 회전 |
| 마우스 좌클릭 | 타깃 락온 |
| `Space` | 미사일 발사 |
| `F1` `F2` `F3` | 카메라 모드 (1인칭/자유비행/3인칭) |
| `F9` | 창모드 ↔ 전체화면 |
| `ESC` | 이전 화면으로 |

**바로 실행하기**: 빌드 없이 [`Excutable/`](./지형%20렌더링%20%26%20헬기%20전투%20시스템%20%28DirectX12%29/Excutable/) 폴더의 exe를 바로 실행할 수 있습니다.

**직접 빌드하기**: Visual Studio에서 [`LabProject08-1-3.sln`](./지형%20렌더링%20%26%20헬기%20전투%20시스템%20%28DirectX12%29/LabProject08-1-3.sln)을 엽니다. PlatformToolset이 `v145`로 설정되어 있어 해당 도구 집합이 없다면 프로젝트 속성 → 일반 → 플랫폼 도구 집합에서 설치된 버전(예: v143)으로 변경 후 빌드하세요.

## 사용 기술

`C++` `DirectX 12` `HLSL` `Win32 API`
